Happy Birthday, Nikita (Cutie) — Wish Lantern Edition
================================================

HOW TO OPEN
Just double-click index.html (or open it in Chrome/Safari/Firefox).
No installation needed. Works on phone and desktop.

FILES
- index.html      the page
- style.css       the design (night sky, lantern, letter, memories)
- script.js       the animations + interactions
- photo.jpeg      her main photo (locket + polaroid in the letter)
- aud.mp3         the background song
- memories/       6 photos shown in the "moments with you" gallery

WHAT'S INSIDE
- A starry night hero with a glowing moon and drifting fireflies
- Her photo in a swinging "locket" frame
- A "release the lantern" button that flies up and unrolls a
  parchment scroll letter with a polaroid + the birthday message,
  typed out by hand
- A "moments with you" memory lane below — 6 tilted polaroids that
  fade in as you scroll, tap any one to view it full-screen
- Fully mobile responsive, keyboard accessible, and respects
  "reduce motion" accessibility settings

EASY TWEAKS
- Change the name: search "Nikita (Cutie)" in index.html.
- Change the date: search "24 August" in index.html.
- Change the message: edit LETTER_TEXT near the top of script.js.
- Add/remove memory photos: drop images into the memories/ folder
  and add or remove a matching
  <figure class="polaroid-card" style="--r:-4deg;"><img src="memories/yourfile.jpg" ...></figure>
  line in index.html (look for the memories-strip block). The --r
  value is just the tilt angle, vary it for a natural scattered look.
- Swap the main photo: replace photo.jpeg with your own image.
- Swap the song: replace aud.mp3 with your own file.
